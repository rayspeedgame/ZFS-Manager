# Target

> [English Version](./target.md)

## 当前产品目标

将 ZFS Manager 打造成一个适用于单主机或小型家庭实验室部署的实用 Web UI，使运维人员无需每次都切换到命令行即可完成常见的池和数据集工作流程。

## 已完成功能

### 池工作流

- 池状态和健康概览
- 可编辑的池属性
- 拓扑可视化
- 向 `log`、`cache`、`special`、`dedup` 和 `spare` 添加设备
- 创建新池，包含：
  - 池属性
  - 根数据集属性
  - 分阶段的数据 vdev 规划
  - 分阶段的辅助 vdev 规划
- 销毁池
- 移除支持的拓扑目标
- 优先使用稳定的 by-id 显示方式（当可用时）

### 数据集工作流

- 数据集和 zvol 清单
- 可展开的数据集树
- 可选的快照显示
- 创建数据集和 zvol 子项
- 编辑数据集属性
- 销毁数据集和 zvol 条目

### UI 功能

- 中英文语言切换
- 基于浏览器语言的首加载语言检测
- 在前端持久化语言偏好
- 已翻译的外壳导航、仪表盘、池工作流、数据集工作流、对话框和命令结果面板

## 前端方向

- `PoolsView` 和 `DatasetsView` 现在是页面容器，而非巨型一体化模板。
- 共享的属性编辑器、命令结果和命令日志集中在 `frontend/src/components/common/` 下。
- 特定于池和特定于数据集的工作流 UI 位于各自的组件文件夹下。
- 实时快照刷新应更新可见数据，而不覆盖正在进行的编辑。
- 用户可见的前端文本应从翻译键中获取，以便添加新语言时无需重构外壳或视图。

## 后续步骤

- 添加更多拓扑操作，如 `replace`、`detach` 和 `offline/online`
- 扩展 SMART 和磁盘健康集成
- 添加更细粒度的权限处理
- 继续将大型工作流逻辑拆分为更小的可组合单元，以提高清晰度
- 随着前端新功能的添加，扩展相应语言覆盖
