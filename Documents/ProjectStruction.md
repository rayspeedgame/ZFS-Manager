# 项目结构说明

## 总体分层

项目分为三个主要部分：

- `backend`
  - 负责 SSH 查询、解析、轮询、缓存、写回和接口输出
- `frontend`
  - 负责展示快照、处理导航、保存交互和结果回显
- `Documents`
  - 负责记录项目说明、阶段目标和协作约定

## 当前后端结构

- `api`
  - 对外提供 REST 和 WebSocket
- `core`
  - 管理配置和共享状态
- `schemas`
  - 定义快照和写回结果模型
- `services`
  - 负责轮询、快照组装和属性写回
- `ssh`
  - 定义命令、执行 SSH、解析输出

## 当前前端结构

- `components/app`
  - 顶栏、侧栏等框架组件
- `components/common`
  - 抽屉、确认弹窗、空状态、调试面板等通用组件
- `store`
  - 快照状态、WebSocket 生命周期、主动刷新与保存请求
- `views`
  - Dashboard、Disks、Pools、Datasets 页面

## 当前设计原则

- 状态真相源尽量放在后端
- 前端优先消费结构化结果，不重复拼装业务数据
- 写回后通过强制刷新拿最新状态，而不是在前端本地猜测结果
- 关键逻辑处补充简洁注释，帮助后续维护
