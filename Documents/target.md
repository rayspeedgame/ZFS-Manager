# 当前阶段目标

本阶段目标是把项目从“结构化展示 SSH 查询结果”推进到“支持部分 pool 属性写回并回显执行结果”。

## 已完成

- 后端维持 `meta + data` 快照模型
- 轮询拆分为不同频率的任务
- Dashboard、Disks、Pools、Datasets 直接消费后端整理后的数据
- Pools 页面支持只读属性、高级属性与可编辑属性分组展示
- Pools 详情页支持编辑可写属性
- 保存前弹出确认窗口，列出本次修改内容
- 点击确认后调用后端逐项执行 `zpool set`
- 返回每个属性的成功或失败情况
- 在同一弹窗中显示结果列表和 SSH Terminal Log
- 保存完成后后端强制刷新一次最新状态

## 当前阶段价值

- 前端已经具备从展示走向有限控制的基础链路
- 写回结果可观测性更强，便于排查失败原因
- 后续扩展 dataset 写回、多语言和更细致的权限控制会更顺手

## 下一阶段可以考虑

- dataset 属性写回
- SMART 健康信息接入
- 多语言支持
- 更细粒度的错误分类与权限约束
