开发一个zfs管理界面，用于管理PVE中的zfs文件系统,

作为 Web 服务运行在 LXC 容器中 
如果你希望这个管理界面是一个可以通过浏览器随时随地访问的 Web 服务，最好的方式是把它关在 PVE 的 LXC 容器里。

* **实现原理：** 在 PVE 中创建一个轻量级的 LXC 容器（比如运行 Debian 或 Alpine）。你的管理界面作为 Web 服务端（如 Node.js, Python FastAPI, 或 Go 程序）运行在容器内。
* **通信方式：** 容器内的后端服务通过配置 SSH 密钥免密登录到 PVE 宿主机（Host），执行 ZFS 命令并将结果返回给前端。
* **安装方式：** 1. 在 PVE 界面一键创建一个 LXC 容器。
    2. 将你的代码部署到容器内（可以使用 Docker，或者直接运行）。
    3. 这种方式下，你的服务崩溃或依赖冲突，完全不会影响 PVE 宿主机的稳定。

我希望具有以下功能

1. 查看目标主机的硬盘信息，并管理硬盘休眠

2. 创建zfs文件系统的pool

3. 修改其pool的各项属性和权限

4. 在pool中创建和管理dataset

根据上述需求，

1. zfs文件系统的数据和目标主机的硬盘数据应该缓存在我的后端程序中，并且定期从主机获取数据，而不是在进入网页后一次性进行拉取

2. 当有网页访问保持连接时增加数据刷新频率
