# 当前阶段目标

本阶段已经从“能展示 SSH 查询结果”推进到“后端提供稳定快照、前端直接消费结构化数据”。

## 已完成

- 后端将状态拆分为 `meta + data`
- SSH 异常时保留最近一次成功数据
- 轮询拆分为不同频率的任务
- Dashboard、Disks、Pools、Datasets 切换到后端整理后的数据
- 顶栏加入来源状态与明显的颜色反馈
- Disks 页支持分区展开
- Pools 页支持拓扑展开与属性分类

## 当前阶段价值

- 前端更轻，后续新增功能更容易
- 断连场景下用户仍能看到最近一次有效状态
- 多 pool 和多频率轮询的基础已经建立

## 下一阶段可以考虑

- SMART 健康信息接入
- pool / dataset 可编辑参数写回
- 属性分页、搜索或筛选
- 更精细的错误分类与提示
